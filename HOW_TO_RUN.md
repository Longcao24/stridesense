# HOW TO RUN

This project has two parts that can be run independently:
- **A. Phone motion-tracking demo** (a web tool that reconstructs trajectories/gait in real time on your phone) — for demonstrations.
- **B. StrideSense pitch deck generation** (matplotlib figures + python-pptx to build the deck) — for producing materials.

> For the user/demo-facing Chinese guide, see [README.md](README.md); for the code structure, see [CODE_OVERVIEW.md](CODE_OVERVIEW.md).

---

## 0. Environment setup

- **macOS** (figures and slides render Chinese/English text and special symbols using the system font **PingFang SC**; on non-macOS you must change the font).
- **Python 3.9+**, install dependencies:

```bash
python3 -m pip install python-pptx numpy matplotlib
```

- **openssl**: bundled with macOS; `serve_https.py` uses it automatically to generate a self-signed certificate on first run.
- **Phone + computer on the same WiFi** (for running the demo).
- Optional: **LibreOffice** (used to convert .pptx to PDF for preview; not required).

## A. Run the phone demo

### 1) Start the server

```bash
cd phone-motion-tracker
python3 serve_https.py            # default port 8443; use python3 serve_https.py 9000 to change the port
```

The terminal will print the address to open on your phone. You can also get the machine's LAN IP manually:

```bash
ipconfig getifaddr en0 || ipconfig getifaddr en1
```

> ⚠️ **The IP changes** (after switching WiFi / a DHCP lease renewal / the computer waking from sleep and reconnecting), so on each startup use the current actual IP, not the old one.

### 2) Open it on the phone

- **English version (default home page)**: `https://<computer-IP>:8443/`
- **Chinese version**: `https://<computer-IP>:8443/index.html`
- Local preview on the computer: `https://localhost:8443/`

On the first "certificate not trusted" prompt → choose **Continue / Visit anyway** (normal behavior for a self-signed certificate).

### 3) Usage flow

1. **① Grant & start sensors** (on the iOS prompt, choose **Allow**).
2. **② Calibrate**: lay the phone flat and keep it still for about 1.5 seconds.
3. Choose a mode:
   - **Gesture mode**: ③ Start recording → draw a circle / write in the air (2–4 seconds) → ■ Stop → the trajectory appears on the right, with replay/export.
   - **Walking mode (PDR)**: strap the phone to your instep/ankle → ▶ Start walk tracking → take 6–8 steps → ■ Stop → view the top-down path + gait panel + 3D.
4. **⬆ Upload**: send the data back to the computer, saved to `uploads/upload_NNN.json` (for offline analysis).

### 4) Stop

Press `Ctrl-C` in the terminal; or, if running in the background: `pkill -f serve_https.py`.

### 5) Troubleshooting "sensor permission denied" on iOS (important)

The authorization step is a **local behavior of iOS Safari and has nothing to do with the server**; once "denied" appears, **refreshing the page or restarting the server does nothing**, because the "deny" is cached on the phone (per site IP:port). Clear it **on the phone**:

1. **Settings → Safari → Motion & Orientation Access**: confirm it is on; if it is already on, **turn it off and back on** (resets the site's memory).
2. Still not working: **Settings → Safari → Advanced → Website Data** → delete `<computer-IP>` (or "Clear History and Website Data").
3. Reopen the page → "Continue" on the certificate → **① Grant access, and this time be sure to choose Allow**.

Avoid pitfalls: during a demo, **open the page on the spot and grant access right then** (do not open it in advance and let it sit for half an hour — iOS will reclaim and reload background tabs); turn off the phone's auto-lock; keep the computer awake and don't let it sleep.

## B. Regenerate the English demo page

The English page `index_en.html` is generated by a script that translates the Chinese `index.html`. **If you change `index.html`, you must rerun it**:

```bash
python3 make_index_en.py          # reads index.html → translates 167 UI strings → writes index_en.html
```

The script includes "zero-match detection": any translation key that fails to match is printed. After generating, it is recommended to verify the JS syntax:

```bash
node --check <(python3 -c "import re;print(re.search(r'<script>(.*)</script>',open('index_en.html').read(),re.S).group(1))")
```

> ⚠️ In the translations, **do not use the English apostrophe `'`** (can't/don't would break the JS single-quoted strings → the whole script throws an error → all buttons stop working); use cannot/do not.

## C. Regenerate the figures and the PPT

### 1) Generate the figures first (the PPT depends on these PNGs)

```bash
python3 make_figs.py          # → figs/fig_traj2d.png, fig_traj3d.png, fig_cv.png (reads uploads/upload_005.json)
python3 make_figs_en.py       # → figs_en/ same as above, English version
python3 make_sensor_fig.py    # → figs/imu_sensors.png (Chinese sensor diagram)
python3 make_sensor_fig_en.py # → figs/imu_sensors_en.png (English)
python3 make_chip.py          # → figs/chip_imu.png (3 commercial IMU chips)
python3 make_hw_figs.py       # → figs/pod_block.png, pod_explode.png, shoe_integ.png
python3 make_assembly_fig.py  # → figs/pod_assembly.png
python3 make_algo_fig.py      # → figs/algo_zupt.png
```

> `figs/parts/*` (real product photos), `figs/video_poster.jpg`, and `video.mp4` are **manually prepared assets, not generated by any script**; if deleted, they must be re-downloaded/re-captured.

### 2) Then generate the PPT

```bash
python3 make_pitch_tech_cn.py # → StrideSense_Tech_CN.pptx (current main one: 6-page Chinese technical deck)
python3 make_pitch_tech_en.py # → StrideSense_Tech_EN.pptx (English version, with speaker notes)
```

Older versions (kept, outdated):
```bash
python3 make_pitch_cn.py      # → StrideSense_Pitch_CN.pptx (11-page early business deck)
python3 make_pitch.py         # → StrideSense_Pitch.pptx (early English deck)
python3 make_slides.py        # → Phone_Motion_Gait_Slides.pptx (the earliest 8-page demo deck)
```

Open the generated `.pptx` files in **PowerPoint / Keynote**; `make_pitch_tech_en.py` already writes English speaker notes (switch to Notes / Presenter view to see them).

## FAQ

| Symptom | Cause / Fix |
|------|------|
| Phone can't open the page / keeps spinning | Not on the same WiFi, or using an old IP; get the IP again and confirm the same network |
| No authorization prompt | Not `https://` (check the yellow bar at the top of the page), or iOS motion permission is off; see A-5 |
| sensor permission denied | A cached "deny"; clear it on the phone, see **A-5** |
| Chinese text turns into boxes in figures/PPT | Non-macOS / PingFang missing; change the font path in `font_manager` |
| `ModuleNotFoundError` | Rerun `pip install python-pptx numpy matplotlib` |
| The whole walking path rotates over a long distance | Slow yaw drift without a magnetometer, which is expected; not noticeable in a short-distance demo |

## Notes

- `cert.pem` / `key.pem`: self-signed certificate, automatically regenerated by `serve_https.py` when missing (**no need to include in distribution**).
- Uploaded data is only sent back when you **actively tap upload**; otherwise it stays entirely local on the phone.
- The port defaults to 8443; if it is in use, release it with `pkill -f serve_https.py` and then start again.
